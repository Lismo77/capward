# Capward

A free, open-source Android app (web later) for building and keeping a
**capsule wardrobe**: fewer, better pieces with a consistent personal style.

- **Free, no ads, no tracking.** Licensed GPLv3. Aimed at F-Droid.
- **Local-first.** Your wardrobe lives on your device. There is no app server.
- **AI is optional.** A confident dresser can do everything by hand. Someone
  newer to fashion can turn on an AI style coach that uses **their own API
  key** from the provider they choose (Claude, OpenAI, Gemini, Mistral,
  OpenRouter, Groq, or a self-hosted model through Ollama).

> Status: early development (v0.2 done). See [docs/ROADMAP.md](docs/ROADMAP.md).

## Features

| | Without AI | With AI (opt-in) |
|---|---|---|
| Wardrobe | Add items with photo, colours, material, seasons, formality, price | *Planned:* fill in item details from a photo |
| Style profile | Write down your palette, shapes and rules | Coach follows them |
| Outfits & wear log | Build outfits slot by slot, see their colour palette, log what you wore each day | *Planned:* outfit ideas from what you own |
| Insights | Most and least worn, not worn in 90 days, cost per wear | *Planned:* gap analysis, "does this purchase fit my capsule?" |
| Coach chat | – | Ask anything, grounded in your actual wardrobe |

## Getting started (development)

The repo holds the Dart code. Platform folders (`android/`, `web/`) are
generated by Flutter the first time you set up.

1. **Install Flutter** (Fedora):
   ```bash
   git clone https://github.com/flutter/flutter.git -b stable ~/development/flutter
   echo 'export PATH="$HOME/development/flutter/bin:$PATH"' >> ~/.bashrc
   source ~/.bashrc
   flutter doctor
   ```
2. **Install the Android toolchain.** The easiest way is Android Studio (it
   brings the SDK and emulator). Then run `flutter doctor --android-licenses`.
3. **Generate the platform folders** (run once from the repo root; it won't
   overwrite `lib/`):
   ```bash
   flutter create --org io.github.lismo77 --project-name capsule_wardrobe --platforms android,web .
   ```
4. **Allow network access in release builds.** Open
   `android/app/src/main/AndroidManifest.xml` and add this line above
   `<application`:
   ```xml
   <uses-permission android:name="android.permission.INTERNET"/>
   ```
5. **Run it:**
   ```bash
   flutter pub get
   flutter test
   flutter run
   ```

### Web version

A web build for iPhone testers is published to
<https://lismo77.github.io/capward/> on every push to `main`. To build or
try it locally:

```bash
tool/build_web.sh                          # fetches SQLite's wasm, builds build/web
cd build/web && python3 -m http.server 8080  # open http://localhost:8080
```

Keep using the same port: browser data is stored per address.

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for how the code is laid out.

## Privacy

- Data is stored in SQLite and the app's private folder on your device.
- With AI off, the app makes no network requests.
- With AI on, requests go directly from your device to the provider you
  chose. The coach sends your style profile and a text list of your items.
  Photos are sent only when you ask the AI to read one.
- Your API key is kept in Android's encrypted keystore.
